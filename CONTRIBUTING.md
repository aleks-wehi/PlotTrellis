# Contributing

**Reporting a bug or asking for a feature:** open an issue at
<https://github.com/aleks-wehi/PlotTrellis/issues>. Include what you did, what you expected,
what happened instead, and the output of `sessionInfo()`. If you can, attach the
`samples.txt` (or a small version of it) and the R script the app downloaded for the figure.

**Code changes:** this GitHub repository is a read-only mirror. The package is developed in
a private repository and copied here by the maintainer, so pull requests cannot be merged on
GitHub. If you have a fix or an idea, open an issue describing it and the maintainer will
make the change upstream.
